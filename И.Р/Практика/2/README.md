# Практическая работа №2
## Аудит готового клиент-серверного приложения

### Состав проекта
- `server.py` — сервер TCP и UDP.
- `client.py` — клиент, отправляющий данные о погоде.
- `format_check.py` — сравнение форматов JSON и XML.
- `Отчет_Практическая_работа_2.docx` — отчет.

### Требования
Python 3.8 или новее. Сторонние библиотеки не требуются.

### Запуск
Откройте терминал в этой папке и запустите сервер:

```bash
python server.py
```

Оставьте сервер запущенным. В другом окне терминала, в этой же папке, запустите:

```bash
python client.py
```

Для сравнения форматов:

```bash
python format_check.py
```

### Что проверить
В отчете описаны ответы на вопросы, штатный запуск и четыре граничных случая.
Скриншоты успешного запуска нужно сделать самостоятельно и добавить в отчет.
